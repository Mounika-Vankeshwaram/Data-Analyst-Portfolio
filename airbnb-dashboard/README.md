## Airbnb Performance Dashboard
End-to-End Power BI Portfolio Project

Project Overview
Analysed Airbnb listing performance across New York City boroughs
to uncover revenue trends, occupancy patterns, and host insights.

Domain: Hospitality & Short-Term Rentals
Tools: SQL · Excel · Power BI (DAX)
Dataset: 500 listings | 16 columns | 2023

Business Problem
- Which boroughs generate the highest revenue?
- How do weekends vs weekdays impact pricing?
- Which property types have the best ADR?
- Who are the top hosts by revenue?

KPIs Tracked
- Total Revenue
- Average Daily Rate (ADR)
- Occupancy Rate (%)
- RevPAR
- Average Review Score

Key Insights
- Entire home listings had significantly higher ADR
- Weekend occupancy spiked 30%+ across peak neighbourhoods
- Top 10% of hosts generated 40%+ of total revenue
- Manhattan led all boroughs in revenue
